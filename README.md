# 🤖 Rule-Based Jarvis Project
Welcome to the Rule-Based Jarvis project! This is a beginner-friendly Python application designed to introduce you to the world of automation and voice interaction.

This system "listens" for human speech, interprets it using rule-based logic, and performs specific commands—like opening websites or responding via text-to-speech.

# 🌟 Features
Voice Recognition: Captures human audio and converts it to text.

Command Execution: Uses predefined rules to trigger system actions.

Speech Synthesis: Jarvis talks back to you using a text-to-speech engine.

Beginner Friendly: Clean code structure that is easy to read and modify.

# 🛠️ Requirements & Installation
1. Prerequisite: 
Ensure you have Python installed on your system. You can check this by typing python --version in your terminal.

2. Clone/Download: 
Download the repository files to your local machine and navigate to the project folder.

3. Install Libraries: 
Open your terminal and run the following commands to install the necessary dependencies:

pip install SpeechRecognition

pip install pyttsx3

If you have a custom 'channelLibrary', ensure it is in your project folder

Note: Depending on your OS, you may also need to install pyaudio to access your microphone: pip install pyaudio.

# 🚀 How to Run
Open your terminal in the project directory.

Run the main script:

Bash: 
python main.py

Speak clearly into your microphone when the program is active.

First, speak "ai" so that Jarvis starts, then start your conversation with commands.
